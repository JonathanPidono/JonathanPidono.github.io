# Refleksi Minggu Kedua: Limit Fungsi

Minggu ini kita masuk ke topik **limit fungsi** — konsep yang menjelaskan nilai yang didekati suatu fungsi ketika `x` mendekati suatu titik tertentu, tanpa harus benar-benar berada di titik itu. Secara matematis ditulis:

```
lim(x→a) f(x) = L
```

Artinya, semakin `x` mendekati `a`, nilai `f(x)` semakin mendekati `L`.

## 1. Jenis-Jenis Limit

Ada empat jenis limit yang dipelajari minggu ini:

1. **Limit biasa** — substitusi langsung
2. **Limit kiri** (`x → a⁻`) — mendekati dari arah kiri
3. **Limit kanan** (`x → a⁺`) — mendekati dari arah kanan
4. **Limit aljabar** — bentuk tak tentu, diselesaikan dengan faktorisasi atau merasionalkan

## 2. Limit Biasa (Substitusi Langsung)

Kalau fungsinya polinom atau fungsi kontinu, limit bisa langsung dihitung dengan substitusi.

**Langkah:**
1. Tentukan titik yang didekati
2. Substitusikan nilai tersebut ke fungsi
3. Sederhanakan hasilnya

**Contoh:**
```
lim(x→2) (3x² - 5x + 1) = 3(2)² - 5(2) + 1 = 12 - 10 + 1 = 3
```

## 3. Limit Kiri dan Limit Kanan

Dipakai untuk fungsi potongan (piecewise). Limit hanya **ada** jika limit kiri = limit kanan.

**Syarat limit ada:**
```
lim(x→a⁻) f(x) = lim(x→a⁺) f(x)
```

**Contoh:** untuk `f(x) = x + 2` jika `x < 1`, dan `f(x) = 3x - 1` jika `x ≥ 1`:
- Limit kiri: `lim(x→1⁻) f(x) = 1 + 2 = 3`
- Limit kanan: `lim(x→1⁺) f(x) = 3(1) - 1 = 2`
- Karena `3 ≠ 2`, maka `lim(x→1) f(x)` **tidak ada**

**Refleksi**: bagian ini paling gampang salah kalau lupa cek dulu apakah titik yang didekati termasuk syarat `x < a` atau `x ≥ a` — harus teliti memilih persamaan yang tepat untuk tiap sisi.

## 4. Limit Aljabar dengan Faktorisasi

Kalau substitusi langsung menghasilkan bentuk `0/0` (tak tentu / indeterminate), harus disederhanakan dulu dengan faktorisasi.

**Rumus penting:**
```
a² - b² = (a - b)(a + b)
a³ - b³ = (a - b)(a² + ab + b²)
```

**Contoh:**
```
lim(x→3) (x² - 9)/(x - 3)
= lim(x→3) (x - 3)(x + 3) / (x - 3)
= lim(x→3) (x + 3)
= 6
```

## 5. Limit Aljabar dengan Merasionalkan

Kalau bentuk `0/0` muncul karena ada akar, dikalikan dengan **sekawan (conjugate)**.

**Rumus sekawan:**
```
(√A - √B)(√A + √B) = A - B
```

**Contoh:**
```
lim(x→4) (√x - 2)/(x - 4)
= (√x - 2)/(x - 4) × (√x + 2)/(√x + 2)
= (x - 4) / [(x - 4)(√x + 2)]
= 1/(√x + 2)
= 1/4
```

## 6. Strategi Menentukan Metode

Alur berpikir yang dipakai untuk memilih metode:

```
Mulai → Substitusi langsung
  → Hasilnya 0/0?
     Tidak → Selesai
     Ya → Bentuk polinom?  → Faktorisasi
          Bentuk akar?     → Merasionalkan
```

**Panduan cepat:**
- Fungsi kontinu → substitusi langsung
- Fungsi potongan → limit kiri dan kanan
- Bentuk `0/0` (polinom) → faktorisasi
- Bentuk `0/0` (akar) → merasionalkan

## 7. Kesalahan yang Sering Terjadi

Beberapa hal yang perlu diwaspadai saat mengerjakan soal:

1. Menganggap bentuk `0/0` sama dengan nol (padahal ini tak tentu, bukan hasil akhir)
2. Salah memilih persamaan pada fungsi potongan
3. Lupa menyederhanakan setelah faktorisasi
4. Hanya mengalikan pembilang dengan sekawan, tapi lupa penyebutnya juga harus dikalikan

## 8. Latihan Soal

Setelah memahami materi, saya mengerjakan latihan soal pilihan ganda yang mencakup:
- Limit biasa dengan substitusi langsung (polinom derajat 2 dan 3)
- Limit kiri dan kanan pada fungsi potongan
- Limit bentuk `0/0` yang diselesaikan dengan faktorisasi (termasuk selisih kuadrat dan selisih kubik)
- Limit bentuk `0/0` yang diselesaikan dengan merasionalkan (akar di pembilang maupun penyebut)

**Refleksi mengerjakan soal**: soal-soal limit kiri/kanan menuntut ketelitian membaca syarat `x < a` vs `x ≥ a` sebelum substitusi. Untuk soal merasionalkan, kunci utamanya adalah mengenali kapan suatu bentuk butuh dikalikan sekawan pembilang atau sekawan penyebut, tergantung di mana akar berada.

|---|---|
| Limit biasa | Substitusi langsung jika fungsi kontinu |
| Limit kiri/kanan | Untuk fungsi potongan; limit ada jika keduanya sama |
