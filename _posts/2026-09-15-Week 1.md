# Refleksi Minggu Pertama: Fungsi

Minggu ini di kelas Calculus, kita membahas konsep dasar **fungsi**: domain, kodomain, range, komposisi fungsi, dan invers fungsi. Berikut rangkuman dan refleksi saya terhadap materi ini.

## 1. Domain, Kodomain, dan Range

**Domain** adalah himpunan semua nilai masukan (input, biasanya `x`) yang membuat fungsi terdefinisi.

**Kodomain** adalah himpunan yang memuat semua kemungkinan nilai keluaran fungsi (himpunan target).

**Range** adalah himpunan nilai keluaran (output) yang benar-benar dihasilkan oleh fungsi — subset dari kodomain.

### Aturan mencari domain

- **Fungsi pecahan**: penyebut tidak boleh nol.
  Contoh: `f(x) = 2 / (x - 3)` → domain: `{x | x ∈ R, x ≠ 3}`
- **Fungsi akar (genap)**: nilai di dalam akar harus ≥ 0.
  Contoh: `f(x) = √(5 - x)` → syarat `5 - x ≥ 0` → domain: `{x | x ∈ R, x ≤ 5}`
- **Gabungan akar dan pecahan**: gabungkan kedua syarat.
  Contoh: `f(x) = √(x + 2) / (x - 1)` → syarat `x + 2 ≥ 0` **dan** `x - 1 ≠ 0` → domain: `{x | x ∈ R, x ≥ -2, x ≠ 1}`

### Mencari range

Untuk fungsi linear pada domain terbatas, substitusikan batas domain ke fungsi.
Contoh: `f(x) = 2x - 5`, domain `-1 ≤ x ≤ 4` → `f(-1) = -7`, `f(4) = 3` → range: `{y | y ∈ R, -7 ≤ y ≤ 3}`

Untuk fungsi kuadrat `f(x) = x² + 1` dengan domain R, karena `x² ≥ 0` maka range: `{y | y ∈ R, y ≥ 1}`

**Refleksi**: bagian yang paling perlu saya latih lagi adalah kombinasi syarat akar + pecahan, karena harus mengingat dua syarat sekaligus dan mengirisnya.

## 2. Invers Fungsi

**Invers fungsi** `f⁻¹(x)` diperoleh dengan menukar peran input dan output — hanya bisa dilakukan jika fungsi **satu-satu (injektif)**.

### Cara mencari invers

1. Ganti `f(x)` menjadi `y`
2. Tukar `x` dan `y`
3. Selesaikan persamaan untuk `y`
4. Ganti `y` menjadi `f⁻¹(x)`

Contoh: `f(x) = 2x + 7`
- `y = 2x + 7`
- `x = 2y + 7`
- `y = (x - 7) / 2`
- Jadi `f⁻¹(x) = (x - 7) / 2`

### Mengapa fungsi kuadrat `f(x) = x²` tidak punya invers di R?

Karena fungsinya **tidak satu-satu** — misalnya `f(2) = 4` dan `f(-2) = 4`, dua input berbeda menghasilkan output yang sama, sehingga proses "menukar balik" jadi ambigu.

**Refleksi**: konsep "satu-satu" ini jadi kunci untuk memahami kenapa tidak semua fungsi bisa dibalik. Ini juga membantu saya memahami kenapa di beberapa soal domain dibatasi — supaya fungsi jadi satu-satu dan punya invers.

## 3. Komposisi Fungsi

**Komposisi fungsi** `(f ∘ g)(x)` berarti: hitung `g(x)` dulu, lalu hasilnya dimasukkan sebagai input ke `f`.

Rumus: `(f ∘ g)(x) = f(g(x))`

Contoh: `f(x) = 2x + 1`, `g(x) = x - 3`
- `(f ∘ g)(x) = f(g(x)) = f(x - 3) = 2(x - 3) + 1 = 2x - 5`

Contoh lain (komposisi tidak komutatif): `f(x) = 3x`, `g(x) = x + 4`
- `(g ∘ f)(x) = g(f(x)) = g(3x) = 3x + 4`
- Ini **berbeda** dari `(f ∘ g)(x) = f(x + 4) = 3x + 12`

**Refleksi**: poin penting yang saya pelajari adalah `(f ∘ g)(x) ≠ (g ∘ f)(x)` secara umum — urutan pengerjaan sangat menentukan hasil, mirip seperti urutan operasi matematika lainnya yang tidak komutatif.

## Kesimpulan Minggu Ini

| Konsep | Inti Pemahaman |
|---|---|
| Domain | Nilai `x` yang membuat fungsi terdefinisi (hindari pembagi nol dan akar negatif) |
| Kodomain | Himpunan target yang mungkin |
| Range | Himpunan output yang benar-benar terjadi |
| Invers | Membalik input-output, hanya untuk fungsi satu-satu |
| Komposisi | `g` dihitung dulu, baru `f`; tidak komutatif |

Secara keseluruhan, materi minggu ini membangun fondasi penting sebelum masuk ke topik kalkulus yang lebih lanjut seperti limit dan turunan. Bagian yang masih perlu saya perdalam adalah menentukan domain untuk fungsi gabungan (akar + pecahan) dan latihan lebih banyak soal komposisi dengan tiga fungsi atau lebih.
